# Pausa Viva

Pausas activas guiadas para la oficina: micro pausas de 3 minutos (cada hora) y pausas largas de 5 minutos (cada 2 horas), con más de 150 ejercicios animados que siguen el tiempo real de cada dosis.

- Funciona en el navegador, sin instalar nada.
- No pide ni guarda datos personales: lo que recuerda queda solo en el navegador de cada persona.
- App en desarrollo: se aceptan sugerencias.

Guía general de pausas activas. No reemplaza la evaluación de un profesional de salud.
