# Pausa Viva

Pausas activas guiadas para la oficina: micro pausas de 3 minutos (cada hora) y pausas largas de 5 minutos (cada 2 horas), con más de 150 ejercicios animados que siguen el tiempo real de cada dosis.

- Funciona en el navegador, sin instalar nada.
- Pausas por zona o por momento del día (para partir el día, ojos cansados, bajar el estrés, antes de irte y más).
- Voz guía opcional en español y música de fondo opcional.
- Racha de días hábiles con compañeros de premio, que se puede pausar por vacaciones o licencia, u ocultar. Cada compañero ganado se puede usar como ícono.
- Recordatorios opcionales e inteligentes: se saltan si hiciste una pausa hace poco, alternan micro y larga según lo que hiciste y respetan la colación.
- Bienvenida breve la primera vez.
- No pide ni guarda datos personales: lo que recuerda queda solo en el navegador de cada persona.
- App en desarrollo: se aceptan sugerencias.

Guía general de pausas activas. No reemplaza la evaluación de un profesional de salud.
